# Aclaria map

A public, mobile-first interactive companion map for Aclaria RPG. Housing is the first layer; exploration and dungeon layers can be added later.

## Evidence and placement

The map is official game artwork; housing names, prices, capacities and locations come from the public [Grand Homestead Market catalogue](https://aclariarpg.fandom.com/wiki/Grand_Homestead_Market?oldid=799). Numbered areas are approximate city/region placements, not exact house coordinates. Pine Estate/Erethune and Lovely cabin/Thaldris remain unplaced.

## Files

- `assets/aclaria-map.jpg`: existing public wiki map, unchanged
- `data/housing.json`: public housing data and normalized map areas
- Site implementation and tests are being prepared through Hermes Kanban.
